# Defensible Choice Study

A short research survey. Participants read committee briefings describing a decision between
two options and judge whether one specified option could be defended on the evidence given.

`index.html` is the whole instrument: one self-contained page, no build step, no dependencies
beyond a webfont. Responses are posted to a collection endpoint configured at the top of the
file.

Taking part requires no account of any kind. A partially completed session is kept in the
browser's own storage, so a reload resumes where the respondent left off rather than starting a
new draw; it is cleared once the response is submitted.

## Contents

This repository deliberately contains **only the respondent-facing page**. The item bank with
its analysis fields, the judge ratings and the study design document are not here — publishing
them would disclose, to anyone who found this repository, which option each briefing treats as
the target and how automated judges rated it.
